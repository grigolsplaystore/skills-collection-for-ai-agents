# Skills Collection for AI Agents

A collection of modular skills and workflows designed for AI coding agents.

## Included Skills

- **[grill-me](skills/grill-me/SKILL.md)**: Stress-tests designs, ideas, and architecture through structured questioning before implementation.
- **[summarize](skills/summarize/SKILL.md)**: Summarizes workspace context and session history into `SUMMARY.md` for rapid context restoration.
- **[teach](skills/teach/SKILL.md)**: Guides multi-session learning with mission planning and structured reference documentation.
